Proyecto D-Lab

D-Lab es un pequeño centro de datos casero: dos Dell OptiPlex trabajando en equipo para dar servicio 24/7, construido para aprender y experimentar con infraestructura real.

Los dos equipos se coordinan como un cluster y se vigilan a sí mismos; sobre esa base corren los servicios personales —monitorización, automatización, base de datos interna y otros— publicados bajo dominio propio con HTTPS.

CPU y RAM de los equipos del cluster, en directo desde Grafana. Cada tarjeta muestra el uso en porcentaje durante las últimas 24 horas: el jumpbox DV0, los hosts físicos D1 y D2 y los cuatro nodos Kubernetes (control y trabajadores) que corren sobre ellos.

Radio SDR remota

Recepción de radio en directo con GQRX (un cliente a la vez).

sdr.elarreglador.eu:1234
Configuración GQRX
  • Rango útil ~0,1–30 MHz (HF, vía upconverter Ham It Up)
  • Device Other
  • Device string rtl_tcp=sdr.elarreglador.eu:1234
  • Input rate 960000
  • LNB LO −125,000000 MHz

Una tasa real de 960000 evita saturar el enlace externo.
