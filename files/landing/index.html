Radio SDR remota

Recepción de radio en directo con GQRX (un cliente a la vez).

sdr.elarreglador.eu:1234
Configuración GQRX
  • Rango útil ~0,1–30 MHz (HF, vía upconverter Ham It Up)
  • Device Other
  • Device string rtl_tcp=sdr.elarreglador.eu:1234
  • Input rate 960000
  • LNB LO −125,000000 MHz

Una tasa real de 960000 evita saturar el enlace externo.
